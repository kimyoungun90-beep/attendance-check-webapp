# ZENIEL 코스트코 근태 관리 V1.2.1

## 실행

ZIP을 별도 폴더에 풀고 **실행.cmd**를 더블클릭합니다. Node.js가 필요합니다.
주소는 `http://127.0.0.1:8766/` 이며 실행 창을 열어두세요.
간단한 확인은 `index.html`을 직접 열어도 됩니다. 누계 저장 위치는 브라우저·주소마다 다르므로 월별 운영은 동일한 주소와 브라우저를 사용하세요.
엑셀 라이브러리는 `vendor/`에 포함되어 있으며 원본을 외부로 보내지 않습니다.

## 월별 운영

1. **엑셀 업로드**에서 매장근무계획관리, 근태관리, 연차신청현황, 영업시간 DB 4개를 선택합니다.
2. 자동 인식된 분석월을 확인합니다. 파일 생성일이 아닌 실제 근태일을 사용합니다.
3. 대체휴일 기준과 입사일을 등록하고 분석합니다.
4. **소명 · 판정 관리**에서 증빙 인정·무단결근 확정·소명 사유를 입력합니다.
5. **분석 결과**에서 **지각 · 근태 엑셀**을 다운로드합니다.
6. 같은 화면에서 기존 완성본을 **마감 기준 양식**으로 선택하고 **마감용 엑셀**을 다운로드합니다.
7. **누계 백업 · 복원**에서 전체 백업을 내려받아 별도로 보관합니다.

같은 월을 다시 분석하면 해당 월만 대체하여 중복을 방지합니다. 선택 초기화는 누계를 지우지 않습니다.
보관함의 월 버튼으로 저장된 결과를 다시 열 수 있습니다. 마감 생성 시에는 원본 3개와 기준 양식이 다시 필요합니다.

## 지각 · 근태 엑셀

`지각 월간표`는 직원별 달력에 지각일의 실제 출근시간을 표시하며 면제 건도 포함합니다.
`지각`에서 기준시간·실제 출근·퇴근·지각 분·반영 감점을 확인합니다.
`소명 및 판정`의 **H열에 제외 또는 무단결근 확정**, **M열에 소명 사유**를 수기로 입력할 수 있습니다.
H열 수정 시 연결된 점수 수식이 재계산되므로 Excel 자동 계산을 사용하세요.
월간표의 색상은 생성 시 판정 기준입니다. 소명 변경 후 수정한 결과를 웹앱에 다시 올려 내려받으면 색상도 갱신됩니다.
수정한 결과를 **이전 월 분석결과**에 올리면 소명 판정과 사유를 읽습니다. 실제 발생 기록은 삭제하지 않습니다.

## 마감 엑셀

기존 완성본의 내부 XML을 사용하여 스타일·열 너비·행 높이·인쇄 설정·도형을 보존합니다. 계산식은 전체 열 조회를 데이터 범위 조회로 바꿔 계산 부담을 줄입니다.
양식의 사번으로 인원을 연결합니다. 신규 사번이 양식에 없으면 생성 중단으로 안내하므로 인사 정보가 갱신된 양식을 사용하세요.
같은 월에는 **기존 수기 보정 유지**로 휴무 보정·대체휴무 기준·비고를 유지합니다.
다른 월에는 기존 수기 기준과 비고를 비웁니다. 대체휴무 기준과 수기 확인란을 작성한 뒤 최종 마감하세요.
매장코드·그룹 입사일 등 원본 4개에 없는 값은 양식에서 유지합니다.
계산 결과를 유지하는 범위에서 참조 범위를 최적화하며, 기존 계산식 전체의 정확성까지 감사한 것은 아닙니다.

## 연도별 누계 확인

조회 연도를 선택하여 2026년·2027년·2028년 및 이후 연도 자료를 각각 누적 조회합니다. 업로드된 새 연도는 자동으로 선택 목록에 추가됩니다. 직원·점포·매니저별 비교와 월별 발생 추이, 면제 건수, 실제 감점, 인원당 발생 건수를 확인합니다.
월·매니저·점포·발생 유형·직원명/사번으로 검색하고 상세내역에서 실제 출근시간과 소명 사유를 확인합니다.
면제한 지각도 발생 건수에 포함하되 감점은 0점입니다. 무단결근은 관리자 확정 건만 출근 미등록과 구분하여 집계합니다.

## 저장과 적용 범위

현재는 PC·브라우저별 저장입니다. 공용 서버 DB·계정·다른 PC 자동 동기화는 없습니다.
브라우저 데이터 삭제·시크릿 모드 종료·주소 변경에 대비해 백업을 보관하세요. 복원은 현재 누계를 대체하며 복원 전 현재 자료를 자동 백업 다운로드합니다.
백업·원본·결과에는 직원 정보가 있으므로 공개 저장소에 올리지 마세요. 앱 배포 시 코드만 배포하세요.
이번 버전은 코스트코 자료를 기준으로 하며 전자랜드와 연차 발생·잔여·수당 계산은 아직 구현하지 않았습니다.
기준시각과 정확히 같은 출근도 지각으로 보는 등 기존 규칙은 유지했습니다. 대체휴일·주차 판정은 입력 기준과 월 경계 자료가 필요합니다.
검증 결과는 `변경사항.md`를 확인하세요.

## V1.2.1 엑셀 속도 개선

마감 엑셀 생성 시 사용하지 않는 외부 연결·깨진 이름을 정리하고 전체 열 수식의 참조 범위를 축소합니다. 사용 중인 이름과 실제로 필요한 외부 연결은 유지합니다. 데이터가 현재 범위를 넘도록 수기로 많이 추가했다면 앱에서 다시 생성하세요. 원본은 변경하지 않습니다.

## V1.2.1 마감 파일 재사용 수정

기존에 생성한 10월 마감 파일을 다음 달 양식으로 사용할 때 발생하던 행 누락 오류를 수정했습니다.
빈 셀을 다른 행까지 잘못 읽던 처리를 행 단위로 고쳤습니다. 기존 생성본의 중복 셀도 정리하여 재사용합니다.
외부 연결 정리 외에 불필요한 강제 재계산 설정과 유효하지 않은 계산 순서 기록도 제거합니다. 자동 계산은 유지합니다.
업데이트 시 ZIP의 파일·폴더를 모두 교체하고 브라우저에서 Ctrl+F5를 누르세요. 화면 상단 VERSION 1.2.1을 확인하세요.
기존 누계 저장 키와 백업 형식은 유지합니다. 교체 전 누계 백업은 별도로 보관하세요.
