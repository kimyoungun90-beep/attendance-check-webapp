01 / DATA SOURCES

월별 파일 업로드

같은 월의 엑셀을 선택해 주세요. 이전 월 결과는 이월 주차와 대체휴일 이력을 이어 붙이는 데 사용합니다.

파일 4개 필수
직전 결과의 숨김 누적데이터를 읽습니다. 이월 주차/대체휴일 연결을 위해 권장.
날짜가 파일명과 달라도 이 월을 적용합니다.
비워두면 업로드한 근태의 해당 월 마지막 일자로 자동 설정합니다.
네 개의 파일을 선택해 주세요.
02 / LEAVE ENTITLEMENT

대체휴일 발생 등록

발생일과 사용 가능한 시작·종료일을 각각 등록합니다. 발생일에 이미 쉰 직원은 다른 날 대체휴일 사용 시 중복을 확인합니다.

날짜 단위 · 월 단위 아님
예시만 안내: 2026-12-25 발생 · 2026-12-01~12-31 사용 가능. 이 예시는 자동 등록되지 않습니다. 12월 25일 이후 입사자는 발생 대상에서 제외되며, 당일 휴무 + 다른 날 대체휴일은 중복 검토합니다.
발생 사유발생일사용기간개수관리
등록된 대체휴일 발생 기준이 없습니다.
03 / PERSONNEL

입사일 · 예외 사번 관리

월별 근무계획에는 입사일이 없으므로 신규 입사자는 여기 등록해야 대체휴일 발생 자격을 정확하게 판정할 수 있습니다.

선택 입력

입사일이 비어 있으면 해당 발생일의 근무계획으로 재직 여부를 참고하되, 확실하지 않은 건은 검토 대상으로 남깁니다. 사번이 달라도 이름으로 연결한 기록은 검증 시트에 따로 남깁니다.

등록된 입사일 없음
04 / REPORT

분석 실행

기준시간에 출근해도 지각입니다. 변경 출퇴근시간은 승인 여부가 불명확하므로 기본적으로 실제 기록을 사용합니다.

준비 완료 · 파일을 선택하고 분석을 실행하세요.
05 / RESULTS

월별 분석 결과 미리보기

분석 후 발생 건수와 검증 대상이 표시됩니다. 최종 판단은 원본 및 소명 결과를 함께 확인하세요.

분석 전
파일을 올리고 분석을 실행하면 미리보기가 표시됩니다.
보고서에는 최종 요약 · 지각 · 출근 미등록 · 퇴근 미등록 · 주간 휴무 · 대체휴일 판정 · 연차 대조 · 소명 처리 · 검증 · 설정·안내 시트와 다음 달 이월용 누적 데이터가 포함됩니다.
06 / VERIFICATION

증빙 인정 · 무단결근 확정

분석 후 아래 내역별로 선택하세요. 증빙 인정은 감점에서 제외되며, 무단결근은 관리자가 확정한 경우에만 -20점을 적용합니다. 변경 후 엑셀 다시 다운로드를 누르면 반영됩니다.

분석 후 검토할 근태 내역이 나타납니다.
